# Claim Boundaries

Allowed claims when validated:

- Qwen Code used this skill to scan attention interfaces and generate migration guidance.
- The target environment passed torch_npu/CANN/NPU preflight.
- Dense-vs-SLA, backward, performance, or multi-card checks passed if corresponding logs are attached.

Do not claim without direct evidence:

- Qwen model internals were modified.
- A fused Ascend custom kernel has been implemented and benchmarked.
- 8-card scaling, tensor/pipeline parallelism, FSDP/HSDP, or full Megatron/MindSpeed training.
- Production quality or model quality parity without public metrics.
- Private or closed-source implementation details.
